# الجاسوس حمزة 🕵️‍♂️

لعبة جماعية (روليت + جاسوس) — مشروع Capacitor يتحول إلى APK تلقائياً عبر GitHub Actions.

## بناء الـ APK
1. ارفع كل محتويات المجلد على مستودع GitHub جديد (فرع main).
2. افتح تبويب **Actions** → **Build Android APK** → انتظر حتى يخضر (5-10 دقائق).
3. من نفس الصفحة نزّل **spy-hamza-apk** من قسم Artifacts → فك الضغط → ثبّت `app-debug.apk` على الهاتف.

## الأيقونة
الصور في `assets/` (icon-only / icon-foreground / icon-background) والـ workflow يولّد منها كل أحجام الأيقونة تلقائياً.
